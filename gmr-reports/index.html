Architectural Advantage

Engineered for Zero-Downtime Microservices

Direct drop-in replacement for legacy reporting engines without rewriting your business templates.

🎯

Deterministic AST Evaluator

Report expressions are evaluated by a parser with a fixed set of operations. No Groovy, no bytecode generated at runtime, nothing reflected into arbitrary classes.

⚡

Sub-Millisecond AOT Compilation

Templates are pre-compiled to a reflection-free binary at build time, so the first render does not pay for parsing the XML.

🔌

Universal Multi-Engine Support

Runs JasperReports (.jrxml) and Eclipse BIRT (.rptdesign) as they are. A binary Crystal Reports .rpt is converted server-side by the Migration Toolkit, with nothing to install: 44 of 44 across the reports SAP ships with Business One.

🛡️

Last-Known-Good Resilience

If a broken template is published, the engine keeps serving the last version that compiled rather than failing the request.

☸️

Cache Synchronised Across Replicas

Compiled templates are shared between pods through Redis, or a shared volume when self-hosted, so an edit made on one replica reaches the rest.

🔒

Zero-Data Retention

Documents are rendered in memory and streamed back. The data you send to be rendered is not written to disk.

🏢

Isolated Multi-Tenant Architecture

Credentials per tenant, token-bucket rate limiting, and monthly quota counted in PostgreSQL so every replica enforces the same allowance.

📦

Python, TypeScript and .NET SDKs

One render call in each. The report type and the output format are arguments rather than separate methods, so a new report type needs no new SDK release.

▦

Vectorial Barcodes and QR Codes

ZXing drawn straight into PDF vectors. No AWT, no X11, nothing in the container that expects a desktop.

📊

Streaming Excel (FastExcel)

Generates .xlsx through streaming ZIP compression, so a large workbook does not turn into an OutOfMemoryError.

🚢

Helm Chart and Kubernetes Operator

A Helm chart for the engine, plus CRDs for report clusters and for templates.

Spring Boot 3 Starter Integration

Add our official starter to your Maven or Gradle build for automatic bean configuration:

<dependency>
    <groupId>com.gmr.reports</groupId>
    <artifactId>gmr-reports-spring-boot-starter</artifactId>
    <version>1.0.0</version>
</dependency>
Inject service bean into your controller:
@RestController
public class InvoiceController {

    @Autowired
    private GmrSpringReportService reportService;

    @GetMapping("/invoice.pdf")
    public ResponseEntity<byte[]> getInvoice() throws Exception {
        byte[] pdf = reportService.renderPdf("invoice", params, items);
        return ResponseEntity.ok().contentType(MediaType.APPLICATION_PDF).body(pdf);
    }
}

Frequently Asked Questions

Technical & Licensing Inquiries

Do we need to rewrite our existing JasperReports templates? ▼

No. GMR Reports was explicitly engineered to ingest standard .jrxml files generated by Jaspersoft Studio. Bands, expressions, parameters, totals, and barcodes render drop-in without template redesign.

How does the Last-Known-Good Fallback protect production? ▼

If a corrupted or invalid XML template is uploaded to a shared volume or hot-reloaded during live operations, GMR Reports detects the parsing failure, raises an alert, and seamlessly continues serving the last valid compiled version in memory. Production document flows never crash.

Can we deploy on Oracle Cloud (OCI), AWS Graviton, and Apple Silicon? ▼

Yes! Our official Docker images on GHCR are multi-architecture (linux/amd64 and linux/arm64). In fact, GMR Reports can run in the OCI Always Free tier consuming less than 1% of the allocated 24GB RAM.

What is the difference between Community and Enterprise licensing? ▼

The Community Edition is free for evaluation and development with public artifacts on Maven Central. The Enterprise Edition provides air-gapped self-hosted Kubernetes Helm licenses, unlimited rendering, Redis/Hazelcast cluster sync, FIPS/banking compliance, and 24/7 dedicated engineering SLAs.
