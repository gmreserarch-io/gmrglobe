Client Integration & Quickstart

Copy pre-configured code snippets with your active API key

TypeScript / Node.js SDK npm install @gmresearch/reports-client 
import { GmrReportsClient } from "@gmresearch/reports-client";

const client = new GmrReportsClient({
  baseUrl: window.location.origin,
  apiKey: "YOUR_API_KEY"
});

// Render dynamic PDF with automatic 429 retry backoff
const pdfBuffer = await client.renderDynamicPdf({
  jrxml: "<jasperReport ...>...</jasperReport>",
  parameters: { INVOICE_NUMBER: "FAC-1001" },
  data: [{ code: "SRV-01", description: "SaaS Subscription", total: 100.0 }]
});
Python SDK pip install gmr-reports-client 
from gmr_reports import GmrReportsClient

client = GmrReportsClient(
    base_url="http://localhost:8080",
    api_key="YOUR_API_KEY"
)

pdf_bytes = client.render(report_type="invoice")
with open("invoice.pdf", "wb") as f:
    f.write(pdf_bytes)
cURL (HTTP REST) 
curl -X GET "http://localhost:8080/api/reports/render?type=invoice&output=pdf" \
  -H "X-API-Key: YOUR_API_KEY" \
  --output invoice.pdf

💎 Archivo Binario Propietario SAP Crystal (.rpt)

ℹ️ Estructura OLE2 de Windows Detectada

El archivo que has subido está en formato binario cerrado de Microsoft/SAP (Compound File Binary Format). El motor GMR Reports Cloud AOT ejecuta en entornos Linux ultraligeros y procesa la especificación de definición abierta Crystal Reports XML (.rpt.xml).

¿Cómo compilar este reporte en GMR Reports?
  • Desde Crystal Reports Designer: Selecciona Archivo > Exportar > Definición de Reporte (XML) y guarda como .rpt.xml.
  • O deja que lo convirtamos ahora: el Migration Toolkit decodifica el .rpt binario en el servidor y te devuelve la definición, sin que instales nada. Medido sobre los 44 informes que SAP distribuye con Business One: los 44 convierten y los 44 renderizan.
