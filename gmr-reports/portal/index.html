Acceso Scale & Enterprise

Registry: ghcr.io / maven.pkg.github.com
🐳 Contenedores Docker / OCI Multi-Arch ARM64/AMD64

Imágenes de alta disponibilidad compiladas AOT para entornos On-Premise y Kubernetes. La descarga es abierta; lo que habilita el uso en producción es su clave de licencia (GMR_REPORTS_LICENSE_KEY).

docker pull ghcr.io/gmreserarch-io/gmr-reports:enterprise
ghcr.io/gmreserarch-io/gmr-reports:enterprise
🍃 Componentes Maven Enterprise (Spring Boot 3) Java 21 / Quarkus

Incorpore la librería starter nativa en su proyecto `pom.xml` apuntando al repositorio empresarial de GMR.

<dependency>
  <groupId>com.gmr.reports</groupId>
  <artifactId>gmr-reports-spring-boot-starter</artifactId>
  <version>1.7.4</version>
</dependency>
<repository>
  <id>github-gmr</id>
  <name>GMR Enterprise Maven Repository</name>
  <url>https://maven.pkg.github.com/gmreserarch-io/gmr-reports</url>
</repository>
📦 SDK TypeScript / Node.js npm private pkg

Cliente tipado para integración rápida con frameworks frontend y microservicios en Node.js.

# Configurar registro en .npmrc:
# @gmreserarch-io:registry=https://npm.pkg.github.com
npm install @gmreserarch-io/reports-client
🐍 SDK Python PyPI / Wheel

Cliente asíncrono para pipelines de datos, Django, FastAPI y reportes automatizados en Python.

pip install gmr-reports --extra-index-url https://token@github.com/gmreserarch-io/gmr-reports
